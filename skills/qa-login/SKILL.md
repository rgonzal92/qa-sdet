---
name: qa-login
description: Sign in to the QA app once in qa-sdet's own browser profile (the user does SSO + MFA in a browser window); later runs reuse that login. Use when the user asks to log in or sign in to the QA app, or after qa-sdet said to run /qa-sdet:qa-login.
---

1. Read `qaBaseUrl`, `ssoHost` and `browser` from `~/.config/qa-sdet/config.json`. If the file is missing, or `browser` is missing or not one of chrome, msedge, firefox, webkit, read `${CLAUDE_SKILL_DIR}/../../references/run-setup.md` and follow its Config section.
2. One call: `playwright-cli -s=qa close; qa-mem browser-open --session qa-login --headed '<qaBaseUrl>'` (a run that was interrupted can leave its browser open on the same profile, and a profile opens in one browser only). It opens the persistent `main` profile. If it fails, show its first stderr line and stop, with the fix: for `browser profile in use`, close the other qa-sdet window (a run in another project folder, or an earlier qa-login) or run `playwright-cli close-all` in that folder, then retry (never `--isolated`: it has no login); for `can't start` or `tool failed`, run `qa-mem doctor` and show the fix it prints (often `playwright-cli install-browser <browser>`).
3. Tell the user: "Complete SSO + MFA in the browser window, wait until the app's home page loads, then reply `done`." Then wait for `done`: the user enters credentials and MFA codes in the browser themselves; they never pass through you.
4. On `done`: `playwright-cli -s=qa-login close`. The browser writes the login into the profile itself.
5. Verify, in one call: `qa-mem browser-open '<qaBaseUrl>' && playwright-cli -s=qa --raw eval "location.host"; playwright-cli -s=qa close` (headless; the close runs on both outcomes). The host is `ssoHost` (if `ssoHost` holds a URL, compare its host), or a login form showed: say the sign-in didn't stick and to run `/qa-sdet:qa-login` again. Otherwise run `qa-mem login-ok` (it records the sign-in, so `qa-mem doctor` stops asking for qa-login) and say: "Signed in. qa-sdet runs reuse this login until the app's SSO session expires; then run /qa-sdet:qa-login again. Next: /qa-sdet:qa-inbox for your tickets."
